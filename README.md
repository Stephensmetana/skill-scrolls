# Smetana Skills

A collection of **11 Agent skills** for software development, game dev, and agentic tooling.

Each skill is a `SKILL.md` file that gives an Agent structured guidance for a specific task —
think of them as focused instruction modules that activate when you need them.

---

## Skills

### Agent Tools

- [`context-optimizer`](agent-tools/context-optimizer/SKILL.md) — Review or design skills, tools, and code to maximize LLM context window efficiency.
- [`skill-cli-generator`](agent-tools/skill-and-cli-generator/SKILL.md) — Generates a SKILL.md and Python CLI script for any API or service, following the Agent Skill + CLI Architecture pattern.

### Chrome Extension Creator

- [`chrome-extension-creator`](chrome-extension-creator/SKILL.md) — Build Chrome extensions (Manifest V3) from scratch.

### Elegance Check

- [`elegance-check`](elegance-check/SKILL.md) — Pause before implementing a solution to run an "elegance check" — a structured moment of reflection on whether the proposed approach is truly the best one.

### Python Dev

- [`python-dev`](python-dev/SKILL.md) — Standards and conventions for creating, running, and managing Python projects.

### Redot

- [`redot-architecture`](redot/redot-architecture/SKILL.md) — Redot 4 GDScript system design.
- [`redot-llm-codegen`](redot/redot-llm-codegen/SKILL.md) — Redot 4 GDScript code generation enforcement.
- [`redot-scene-design`](redot/redot-scene-design/SKILL.md) — Redot 4 scene structure and boundaries.
- [`redot-signals-eventbus`](redot/redot-signals-eventbus/SKILL.md) — Redot 4 node/scene communication: signals, EventBus, callbacks.

### Utilities

- [`directory-scanner`](utilities/directory-scanner/SKILL.md) — Scan a directory's immediate subdirectories and produce a structured report that describes what each one contains.
- [`skills-index`](utilities/skills-index/SKILL.md) — Scan a skills folder (or any folder containing SKILL.md files) and generate a structured index, report, or README that lists every skill with its name, description, category, and bundled resources.

## Structure

```
skills-root/
├── <category>/
│   └── <skill-name>/
│       ├── SKILL.md          # skill instructions + YAML frontmatter
│       ├── scripts/          # helper scripts bundled with the skill
│       ├── references/       # reference docs loaded on demand
│       └── assets/           # static files used in output
```
