# Markdown Writer Skill

Produce well-structured Markdown documents and chat logs from the Claude.ai website on demand.

---

## Trigger Phrases

| User says…                               | Action                            |
|------------------------------------------|-----------------------------------|
| "write a markdown / document"            | → **Document mode** (see below)   |
| "create / generate / make a markdown"    | → **Document mode**               |
| "document the entire chat"               | → **Chatlog mode** (see below)    |
| "export / save / log the chat"           | → **Chatlog mode**                |

---

## Document Mode

Generate a polished Markdown file matching the user's requested topic.

### Filename convention
```
{kebab-case-topic}.md
```
Example: `quarterly-sales-report.md`

### Required document structure

```markdown
# {Title}

> {One-line summary or subtitle}

---

## Overview
…

## {Section 2}
…

## {Section N}
…

---

*Generated by Claude · {ISO date}*
```

### Rules
- Use proper ATX headings (`#`, `##`, `###`)
- Use fenced code blocks with language tags where relevant
- Use tables, bullet lists, numbered lists as appropriate for the content
- Keep prose clear and concise
- Always end with the attribution footer

## Chatlog Mode

Triggered by: "document the entire chat", "export the chat", "save the conversation".

### Filename convention
```
claude-chatlog--{topic}--{YYYY-MM-DD_HH-MM}.md
```
- `{topic}` = short kebab-case description of the conversation subject (infer from context)
- Datetime = current local time at moment of export

Example: `claude-chatlog--marketing-strategy--2026-05-02_14-30.md`

### Required chatlog structure

```markdown
# Chat Log: {Topic}

**Exported:** {YYYY-MM-DD HH:MM}  
**Messages:** {total count}

---

## Conversation

### 👤 User · {timestamp or message #}
{verbatim or faithful summary of user message}

---

### 🤖 Claude · {timestamp or message #}
{verbatim or faithful summary of assistant message}

---

…(repeat for every turn)…

---

*Exported from Claude.ai · {ISO date}*
```

### Rules
- Include **every** message turn — do not skip or truncate
- If exact timestamps are unavailable, use sequential message numbers (`Msg 1`, `Msg 2`, …)
- Preserve code blocks, lists, and formatting from the original messages
- Infer the `{topic}` from the dominant subject of the conversation
